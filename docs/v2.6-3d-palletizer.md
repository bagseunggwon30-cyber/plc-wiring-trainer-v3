# v2.6 3축 팔레타이징 디지털 트윈

## 범위

`🦾 3D 실습`은 결선 작업장 안에서 실행되는 오프라인 3축 갠트리 시뮬레이터다. X/Y/Z 리니어 축, 서보 상태, 원점과 양방향 리미트, 절대 위치결정, 조그, 그리퍼, 제품 파지/해제 및 팔레트 행·열·단 패턴을 모델링한다.

외부 교육 프로그램의 바이너리, DLL, 3D 모델, 텍스처, UI, 로그인 코드, 통신 프로토콜은 복사하지 않았다. Three.js와 기본 도형을 사용해 독립 구현했으며 계정 정보도 저장하지 않는다.

## 사용 순서

1. 앱 상단에서 `🦾 3D 실습`을 연다.
2. `SERVO ON` 후 `전축 원점`으로 X/Y/Z 원점 센서를 확인한다.
3. 축별 `−/＋` 버튼을 누른 동안 조그하거나, 목표 mm를 입력하고 `ABS`를 누른다.
4. 팔레트 행·열·단을 정하고 `패턴 적용`을 누른다.
5. `자동 시작`을 누르면 픽업과 적재 사이클이 진행된다.

프로젝트 JSON에는 축 위치, 팔레트 설정과 적재 결과가 `palletizer3d` 필드로 저장된다. 다시 불러올 때 축이 자동 재가동되지는 않는다.

## XG5000 스타일 내부 주소

이 주소는 학습용 메모리 이미지다. 현재 버전은 실제 PLC, 시리얼 포트 또는 네트워크에 쓰지 않는다.

| 주소 | 방향 | 의미 |
|---|---|---|
| `M100` | 명령 | 자동 시작 |
| `M101` | 명령 | 정지 |
| `M102` | 명령 | 알람/시퀀스 리셋(적재 결과 유지) |
| `M110` | 명령 | 전축 원점복귀 |
| `M120` / `M121` | 명령 | 그리퍼 닫기 / 열기 |
| `M130` | 명령 | 전축 서보 ON/OFF |
| `M140` / `M141` / `M142` | 명령 | X / Y / Z 절대 위치결정 실행 |
| `M150`~`M155` | 명령 | X+/X−/Y+/Y−/Z+/Z− 조그 |
| `D100` / `D102` / `D104` | 설정 | X / Y / Z 목표 위치(mm) |
| `D110` | 설정 | 위치결정·조그 속도(mm/s) |
| `M200` / `M201` / `M202` | 상태 | 자동 운전 / 완료 / 알람 |
| `M210`~`M212` | 상태 | X/Y/Z BUSY |
| `M220`~`M222` | 상태 | X/Y/Z 원점 완료 |
| `M230`~`M232` | 상태 | X/Y/Z 위치결정 완료 |
| `M240` / `M241` | 상태 | 그리퍼 닫힘 / 제품 파지 |
| `M250`~`M255` | 상태 | 각 축 음·양 리미트 |
| `D200` / `D202` / `D204` | 상태 | X / Y / Z 현재 위치(mm) |
| `D210` / `D211` / `D212` | 상태 | 적재 수 / 자동 스텝 / 완료 사이클 수 |

렌더러 콘솔이나 향후 로컬 브리지에서는 `PLCTrainerPalletizer3D.readDevice(address)`와 `writeDevice(address, value)`를 사용할 수 있다. 실제 XBC-DR32H와 연결할 때는 이 API 앞에 별도 로컬 어댑터, 통신 타임아웃, 연결 허용 스위치와 비상정지 인터록을 추가해야 한다.

## 현재 한계

- XG5000 프로젝트 파일이나 래더를 직접 해석하지 않는다.
- 실제 XBC-DR32H, 위치결정 모듈, 서보 드라이브와 통신하지 않는다.
- 충돌, 관성, 토크, 진공 압력은 교육용 논리 수준이며 실제 기계 안전 검증에 사용할 수 없다.
- 실제 장비 적용 전에는 하드웨어 E-stop, 오버트래블 리미트, 안전릴레이와 저속 단독 시운전이 필요하다.

## 주요 파일

- `src/runtime/palletizer-runtime.js`: 결정론적 3축/자동 시퀀스와 M/D 메모리
- `src/ui/palletizer-3d.js`: Three.js 장면, 카메라와 조작 패널
- `assets/vendor/three.min.js`: 오프라인 3D 엔진
- `tests/v26-palletizer-runtime.test.js`: 원점·리미트·위치결정·자동 적재 회귀 테스트
