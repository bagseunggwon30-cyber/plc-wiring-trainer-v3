# v2.7 자동화 제어 실습실

## 결과

기존 결선 작업장의 `🏭 자동화 실습실` 보기에 다음 네 실습을 통합했다.

1. 기존 3축 팔레타이징
2. 2축 위치결정·서보 제어
3. MPS 공급·가공·이송·배출 플랜트
4. 공압 밸브·복동 실린더·진공

각 실습 런타임은 DOM이나 실제 PLC 통신에 의존하지 않는 고정 시간 간격
상태 모델이다. 큰 `tick`과 같은 길이의 작은 `tick` 결과가 같도록 구성했다.

2축 서보와 MPS 화면은 로컬 SoV-KDP 빌드에서 변환한 전체 원본
장비 어셈블리를 주 시각 모델로 사용한다. Unity 동작 코드는 가져오지 않았으며,
축 이동·센서·액추에이터·공압 계산과 안전 인터록은 Electron에서 독립 구현한 런타임이
구동한다.

장면에는 실습 장비만 배치한다. 강의실·의자·벽·테이블·장식 소품은 로드하지
않으며, 동작이 없을 때는 렌더 루프도 멈춘다.

## 2축 서보

지원 기능:

- 축별 서보 ON/OFF, JOG, 정지, 원점복귀
- ABS/INC 위치결정, 속도·가속·감속, 전·후진 리미트
- 2축 직선 보간과 포인트 테이블
- DOG, BUSY, IN POSITION, HOME, ALARM 상태
- LS XBF-PD02A+XDL-L7SA004A, Mitsubishi QD75D2N+MR-J4-A, Mitsubishi
  QD77MS2+MR-J4-B를 서로 독립된 장비 프로필로 선택
- 선택한 펄스 프로필의 8심 차동 결선 그래프와 교육용 3D 단자 오버레이
- 차동쌍 단선, +/− 반전, X/Y축 교차, 1차/2차 펄스쌍 교차 자동 진단
- 프로필별 결선·고장·체크리스트 저장, 제조사 전환 시 출력 안전 OFF
- 저장 시 좌표·포인트·프로필 유지, 복원 시 모든 운동 정지

QD75D2N 펄스 프로필과 QD77MS2 SSCNET 프로필은 서로 겹치지 않는 선택 세션과
교육용 주소표를 사용한다. QD77 주소표는 랙의 헤드 I/O·버퍼 메모리를 고정값으로
주장하지 않는 프로필 로컬 시뮬레이션 계약이며, 다른 프로필 주소 쓰기는 거부한다.
이전 SoV 어셈블리의 제조사 불명 `INPUT/OUTPUT/P24/N24` 공통 소켓은 저장 데이터에서
삭제하지 않되 선택형 서보 결선 화면에서는 숨기고 판정에도 사용하지 않는다.

화면의 주 장비 외형은 원본 활성 계층 전체를 보존한
`assets/imported/sov-kdp/models/servo2-workshop.glb`다. Electron 런타임의 축 좌표를
원본 어셈블리 안의 X/Y 이동 노드에 연결해 표시한다.

### LS 교육 조합

`XBC-DR32H + XBF-PD02A + 2 × XDL-L7SA004A 계열 + 2 × XML-SB04A 계열`

- XBF-PD02A: 2축 차동 라인드라이버, 축당 최대 2 Mpps
- X축: `A18 FP+`, `A17 FP−`, `A16 RP+`, `A15 RP−`
- Y축: `B18 FP+`, `B17 FP−`, `B16 RP+`, `B15 RP−`
- 축별 `OV+`, `OV−`, `DOG`, `INP`, `CLR`, `HOME`을 별도 상태로 취급
- L7S CN1 예: `9 PF+`, `10 PF−`, `11 PR+`, `12 PR−`, `47 SVON`,
  `17 ALMRST`, `18 EMG`, `45 INPOS`, `38/39 ALARM`, `40/41 READY`
- XBF는 최대 2 Mpps지만 L7S 라인드라이버 수신 한계가 1 Mpps이므로 조합
  경로는 1 Mpps로 제한한다. 10 m 이하의 실드 트위스트 페어를 사용한다.
- XBF 출력 방식·논리와 L7S `P4-00` 입력 방식·논리가 일치해야 한다.
- XBF 위치결정 모듈에는 서보 전용 SVON/ALARM 단자가 없으므로 일반 PLC I/O와
  안전회로를 통해 별도 결선해야 한다.

- [L7S 200 V V2.4 매뉴얼](https://www.ls-electric.com/upload/customer/download/d462ae5d-d496-439e-b71e-ad374d8a843c/Manual_XDL-L7S_200V_V2.4.pdf)

### Mitsubishi 교육 조합

`Q03UDVCPU + Q61P + QD75D2N + 2 × MR-J4-40A + 2 × HG-KR43`

- QD75D2N: 2축 차동 출력, 최대 4 Mpps, 축당 위치결정 데이터 600개
- QD75D2N은 축마다 별도 40핀 커넥터가 있는 구조가 아니라 한 개의 AX1/AX2
  40핀 커넥터를 공유한다. 축 1은 `1A15/16 PULSE F±`, `1A17/18 PULSE R±`,
  축 2는 `1B15/16 PULSE F±`, `1B17/18 PULSE R±`다.
- MR-J4 CN1 예: `10 PP`, `11 PG`, `35 NP`, `36 NG`, `15 SON`, `19 RES`,
  `42 EM2`, `43 LSP`, `44 LSN`, `48 ALM`, `49 RD`
- SH-030107-V 3-13의 QD75D 직접 결선은 `F+ → PP(10)`, `F− → NP(35)`,
  `R+ → PG(11)`, `R− → NG(36)`이며 명령 케이블은 10 m 이하로 제한한다.
- QD75 `Pr.5`/`Pr.23 bit0`과 MR-J4 `PA13`의 명령 방식·논리를 함께
  검사한다. 차동 출력 논리는 서로 반대로 설정하며 PA13 변경 뒤 전원을 재인가한다.
- 4 Mpps 이하, 10 m 이하의 실드 트위스트 페어를 사용하고 QD75 측 제어반에서
  실드 종단을 확인한다. QD75D 직접 결선에 공통선을 임의로 필수 추가하지 않는다.
- QD75의 모듈 축 오류와 MR-J4의 서보 ALM을 하나의 비트로 합치지 않는다.
- INP 등 일부 MR-J4 신호 핀은 파라미터 배정에 따라 달라질 수 있어 장비팩에
  `assignable`로 표시한다.

## MPS

MPS 런타임은 SoV-KDP 장비의 18개 출력과 27개 입력을 기본 인터페이스로 사용한다.
컨베이어 위 작업물 좌표와 각 실린더·서보 위치는 고정 스텝으로 계산한다.

- `O0/O1`: 공급 전진/후진, `O2`: 드릴 실린더
- `O3/O4`: 분배 전진/후진, `O5/O6`: 배출 전진/후진
- `O7/O8`: 공압 리프트 전진/후진, `O9`: 진공
- `O10/O11`: 언로딩 전진/후진, `O12`: 스토퍼, `O13`: 드릴 모터
- `O14`: 컨베이어, `O15/O16/O17`: 적색/황색/녹색 표시등
- `I0~I13`: 7개 실린더의 전진·후진 한계
- `I14~I19`: 공급·분배·유도·정전용량·종단·진공 센서
- `I20~I23`: 예약, `I24/I25/I26`: 리프트 서보 RLS/DOG/FLS

복솔 밸브는 양쪽 출력이 모두 꺼지거나 켜지면 직전 방향을 유지한다. 강재와
플라스틱은 센서 응답만 다르며, 재질별 분류 순서는 앱에 내장하지 않았다.
XG5000 래더 또는 수동 `O0~O17` 출력이 공급·가공·배출 순서를 직접 결정한다.

프로필 주소는 LS `P/M/D` 및 Mitsubishi `X/Y/M/D` 형식의 앱 내부 교육용
메모리다. 실제 PLC 전송 드라이버와 네트워크 소켓은 아직 없다.

화면의 주 장비 외형은 컨베이어 일부만 분리한 모델이 아니라 공급·가공·이송·
배출 모듈을 포함한 전체 원본 스테이션
`assets/imported/sov-kdp/models/mps-complete-station.glb`다. 강재·플라스틱
작업물도 원본 메시를 복제해 Electron 런타임 좌표에 배치한다.

## 공압

공압 런타임에는 전기 Netlist와 분리된 포트·튜브 그래프가 있다.

```text
공급원 OUT → 서비스유닛 IN/OUT → 분배기 → 5/2 밸브 P
                                     ├→ 밸브 A → 실린더 A
                                     ├→ 밸브 B → 실린더 B
                                     └→ 진공 패드
```

- 서비스 유닛 설정압
- 5/2 단솔: 무여자 시 스프링 후진
- 5/2 복솔: 무여자 시 마지막 스풀 상태 유지
- A/B 동시 여자 인터록
- 복동 실린더 스트로크와 전·후진 유량 조절
- 진공 명령·제품 감지·흡착 확인
- 미결선 포트와 호스 누설 고장 삽입
- 전진 → 대기 → 후진 자동 1사이클

이 모델은 결선·시퀀스 학습용이다. 압축성, 힘, 충격, 온도, 실제 유량계수,
잔압 및 안전밸브를 계산하는 공학 해석기가 아니다.

원본 SoV-KDP 공압 실습실의 `WorldObject`에는 완성된 공압 회로가 저작되어 있지
않았다. 따라서 원본 서비스 유닛·분배기·5/2 밸브·속도조절기·복동 실린더
프리팹만 조합했다. 실습실·작업대·의자 등 환경 메시를 가져오지 않았으며,
튜브 그래프와 실린더 동작은 위 독립 공압 런타임이 담당한다.

## SoV 3D 편집

- 숫자 `1~6`: 제어, 이동, 장비 삭제, 전기 결선, 공압 튜브, 선 삭제
- 한 포트에는 한 연결만 허용하며 장비를 움직이면 연결선·튜브도 따라감
- 전기선은 저비용 3D 선, 공압 호스는 6면 원통형 튜브로 표시
- 다섯 3D 화면은 동일한 카메라 설정을 공유한다. 기본 `3ds Max` 설정은 `Alt+가운데 버튼` 오빗, 가운데 버튼 팬, 휠 줌이며, 이전 우클릭/드래그 조작은 `기존 조작` 설정으로 보존한다.
- 서보·MPS는 고정 장비의 I/O 포트 결선을 지원하고, 공압 실습은 핵심 5개
  프리팹의 이동·삭제·튜브 연결을 지원
- 편집 결과는 프로젝트 JSON의 `automationLab.editor`에 저장

현재 포트 위치는 실습 동작에 맞춘 기능 좌표다. 원본 전체 24종 공압 팔레트와
각 `LocalMesh`의 정밀 포트 좌표, 원본 `.kdp` 파일 호환은 후속 구현 범위다.

## 선별 자산 이식

`SoV-KDP 1.1.9K` Unity 로컬 빌드에서 활성 장비 메시 계층과 관련
텍스처만 선별 변환했다.

- 장비 전용 27개 GLB. 현재 앱은 제어·전원, NPN/PNP 센서, 릴레이·타이머·카운터, 공압 부품과 MPS/서보 설비를 3D 장비 검사실에서 선택한 한 개씩 지연 로드한다.
- 이 3D 외형은 교육용 관찰 자산이며, 정확 품번의 단자·정격·검토 증거는 제조사 매뉴얼 기반 프로필에서만 가져온다.
- 전체 어셈블리: `servo2-workshop.glb`, `mps-complete-station.glb`
- 개별 장비: PLC 모듈, 서보 앰프, 서비스 유닛, 분배기, 속도조절기,
  5/2 밸브, 실린더, 센서, 작업물
- 강의실·의자·벽·테이블·장식 소품과 중복 어셈블리는 제외
- 텍스처는 각 GLB에 최대 2048px WebP로 내장하며 별도 PNG 사본은 없음
- 변환 결과: `assets/imported/sov-kdp/`
- 재현 스크립트: `scripts/extract-sov-kdp-assets.py`
- 원본 오브젝트 ID·파일·SHA-256: `assets/imported/sov-kdp/manifest.json`

이식된 것은 보이는 장비 자산이다. Unity에서 컴파일된 제어·물리·UI 동작을
Electron에서 실행하거나 복사한 것이 아니며, 실습 동작은 이 프로젝트의 독립
JavaScript 런타임으로 구현했다.

다음 항목은 이식하지 않았다.

- EXE, DLL, 관리/네이티브 코드와 Unity 동작 코드
- 로그인·계정·자동로그인 정보
- 인증·라이선스·USB 동글·기간 제한
- 외부 서버·네트워크 클라이언트·PLC 프로토콜 구현
- 사용자 저장 데이터

## 프로젝트 저장

프로젝트 스키마는 9다.

```json
{
  "palletizer3d": "기존 v2.6 호환 상태",
  "automationLab": {
    "schemaVersion": 1,
    "activeLab": "servo2",
    "labs": {
      "servo2": {},
      "mps": {},
      "pneumatic": {}
    },
    "editor": {
      "servo2": {},
      "mps": {},
      "pneumatic": {}
    }
  }
}
```

이전 프로젝트에 `automationLab`이 없으면 기본 안전 정지 상태로 생성한다.
JSON 복원 후 자동운전, 컨베이어, 실린더 및 축 운동은 자동 재개하지 않는다.
