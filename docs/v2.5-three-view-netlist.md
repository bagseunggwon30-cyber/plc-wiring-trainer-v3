# v2.5 실물 · 종이 결선도 · 시퀀스 공통 Netlist 구현

## 설계 원칙

전기적으로 동일한 회로를 화면별로 복제하지 않는다.

```text
S.devices ────────────── 장비 실체
S.wires   ────────────── 실제 전기 연결 / Netlist
   │
   ├─ 실물 제어반 renderer
   ├─ 종이 결선도 renderer
   └─ 시퀀스 renderer

diagramLayouts
   ├─ schematic ──────── 종이 결선 심볼 좌표만 저장
   └─ sequence ───────── 시퀀스 심볼 좌표만 저장
```

따라서 `PB.12 → MC.A1`을 시퀀스 화면에서 생성해도 제어반 화면에서 동일한 두 실제 단자 사이에 와이어가 생성된다.

## 주요 파일

- `src/ui/multiview-core.js`: 장비 → 시퀀스 심볼 변환, I/O 표 모델, 공통 도면 헬퍼
- `src/ui/multiview-ui.js`: 보기 전환, SVG 렌더링, 단자 결선, 심볼 이동, 선 삭제, 인쇄/PDF 창
- `examples/v25-self-hold-three-view.json`: 세 화면 동기화 확인용 자기유지 예제

## 구현 범위

### 종이 결선도

- 모든 배치 장비를 장비 블록으로 표시
- 실제 terminal ID와 전기 역할 표시
- 단자 클릭 → 단자 클릭으로 `connectTerms()` 호출
- 공통 와이어 번호 표시
- Net 전기 역할 표시
- 심볼별 독립 좌표 저장
- 자동 배치, 화면 맞춤, 확대/이동
- 와이어 선택/삭제
- 인쇄/PDF용 별도 창

### 시퀀스

- NO, NC, 코일, 램프 심볼
- MY2N/타이머의 Form-C 접점은 3단자 전환접점으로 표현
- MC의 코일·보조접점·주접점이 하나의 실제 MC 단자 데이터에 연결
- 시뮬레이션 ON 시 live terminal과 coil state를 도면에 강조
- 전용 심볼이 없는 장비도 실제 단자를 I/O 블록으로 표시

### PLC I/O

- PLC/증설 I/O 단자 목록
- Rack runtime이 계산한 XG5000 P 주소
- 실제 `S.wires`에서 연결 상대 표시
