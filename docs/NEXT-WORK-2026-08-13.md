# 다음 작업 목록 — 2026-08-13

이 문서는 3축 팔레타이저, 3D 결선 엔진, 3D 자산 로더, XG-SIM 연동 안정화 작업 이후 남은 항목을 정리한다.

## 이번 반영에서 완료된 작업

- Blender 3축 팔레타이저를 1.38 MB GLB, 72,156 triangles로 최적화했다.
- GLB의 회전된 루트와 부모 계층을 반영해 X/Y/Z를 실제 월드축으로 이동하도록 수정했다.
- GLB 전환 뒤에도 홈·리미트 LED가 보이도록 상태 표시를 runtime layer로 분리했다.
- 창 포커스 이탈, 문서 숨김, 실습 화면 전환 시 진행 중인 JOG를 강제로 해제한다.
- 팔레타이저 자동 운전의 제품·팔레트·진공 handshake, watchdog, RESET 및 복원 안전 정책을 강화했다.
- 3D 단자에 `maxConductors` 용량을 도입했다. 기본값은 1이며 실제로 분기 결선이 허용된 단자만 명시적으로 늘릴 수 있다.
- 결선 드래그 중에는 가벼운 Line preview를 사용하고 결선 확정 후에만 TubeGeometry 케이블을 만든다.
- 3D 모델 로더에 timeout, Abort, 실패 재시도, ref-count, LRU, dispose 및 충돌 없는 `collection:file` 주소를 적용했다.
- Electron 창의 외부 이동·팝업을 차단하고 XG-SIM이 없는 PC에서도 만들 수 있는 offline 패키징 구성을 추가했다.
- XG-SIM 연결 중복, 오래된 세션 frame, 잘못된 ack 및 profile 전환 경쟁을 fail-closed로 차단했다.

## 우선순위 1 — 실제 XG-SIM 권위 제어

현재 Native Host v1은 새 세션 증거인 `sessionId`, `sessionNonce`, `hostEpoch`, project SHA echo를 제공하지 않는다. 따라서 앱은 의도적으로 `diagnostic-only`로 연결하며 PLC 권위 제어를 허용하지 않는다.

다음 작업:

1. Native Host 응답과 frame에 세션 증거 및 원본 sequence/timestamp를 추가한다.
2. input commit 응답에 accepted/rejected 주소와 실제 적용 결과를 반환한다.
3. 53개 M device와 DI bank를 완전한 BOOL snapshot으로 제공한다.
4. Visual Studio Build Tools와 .NET Framework 4.7.2 targeting pack이 설치된 PC에서 Host를 빌드한다.
5. 실제 XG5000/XG-SIM 프로젝트로 connect → input write → frame read → safe stop E2E를 수행한 후에만 authoritative 모드를 연다.

## 우선순위 2 — 실제 단자 자료 보강

- EXP2-700 HMI와 XY-MD02는 실장비 사진 또는 제조사 도면을 기준으로 전원·RS-485 단자 위치와 명칭을 확정한다.
- MDR-100-24의 HMI/XY-MD02 전원 분배와 HMI↔XBC-DR32H RS-485 결선을 저장 JSON에서 재현하는 통합 시나리오를 추가한다.
- `maxConductors`는 실제 단자 구조상 두 도체가 허용되거나 점퍼 단자인 경우에만 2 이상으로 설정한다. 확인되지 않은 단자는 기본값 1을 유지한다.
- XBC-DR32H 전면 단자 번호와 3D hit target의 픽셀·좌표 일치 검사를 실제 정면 캡처로 보강한다.

## 우선순위 3 — 3D 성능과 가독성

- `mps-complete-station.glb`는 약 69.3 MiB다. 정적 프레임 병합, 반복 부품 instance, 작은 나사·홈 bake를 적용해 우선 30 MiB 이하를 목표로 한다.
- XBC-DR32H는 공통 조명에서 전면 라벨 대비가 낮다. ACES tone mapping, exposure 및 장비별 재질 보정을 검토한다.
- 팔레타이저 GLB가 성공한 뒤 procedural fallback은 숨겨져 있지만 메모리에 남아 있다. 로딩 proxy와 상태 LED를 완전히 분리한 뒤 fallback geometry를 dispose한다.
- Renderer main chunk가 약 594 kB이므로 자동화 실습실과 3D 장비 catalog를 dynamic import로 분리한다.
