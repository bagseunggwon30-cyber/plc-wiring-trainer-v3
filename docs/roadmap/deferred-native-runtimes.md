# 자동화·미션·3D 재도입 조건

4.2.0에서는 실제 UI 진입점과 구현체가 없던 자동화, 빈 미션 평가기, XG-SIM 및 3D 실행 계약을 제거했습니다. 복구 경계는 `pre-native-refactor-4.2.0-2026-08-22` Git 태그입니다.

문서 호환을 위해 `missionState`, `scenario`, `viewLayout` 필드는 schema v5에 남아 있으며 알 수 없는 legacy 확장도 그대로 보존합니다. 이 필드가 존재한다고 실행 기능이 제공되는 것은 아닙니다.

재도입 전 다음 조건을 모두 충족해야 합니다.

- 2D와 3D가 별도 넷리스트를 만들지 않고 같은 device, terminal, conductor ID를 사용할 것
- 미션 목표가 실제 전기 검증 코드와 typed target으로 평가되고 빈 목표를 성공으로 처리하지 않을 것
- 자동화 런타임이 오프라인 회로 결과와 불일치를 명시하고 실제 PLC 쓰기를 수행하지 않을 것
- XG-SIM 보조 프로세스에 timeout, 크기 제한, watchdog, fail-safe reset과 프로젝트 신원 검증을 적용할 것
- Direct3D 렌더러를 실제 지원 GPU/DPI에서 반복 검증하고 교육용 3D 자산을 전기 근거로 사용하지 않을 것
- 실제 설치 환경이 없으면 해당 기능을 완료나 검증 통과로 표시하지 않을 것
