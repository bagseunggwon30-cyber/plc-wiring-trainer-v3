# XG-SIM 재도입 조건

현재 제품에는 XG-SIM 프로세스, 브리지, 프로토콜, 메뉴가 없습니다.

재도입 전 다음 계약이 필요합니다.

- 지원 PLC 계열과 XG5000/XG-SIM 버전의 명시적 호환표
- 별도 프로세스의 시작·종료·시간 제한·자식 프로세스 정리
- 프로젝트 원본 불변과 candidate/checkpoint 분리
- 오프라인 검증과 실제 시뮬레이터 결과의 불일치 표시
- 실패 시 fail-closed, 사용자 승인 없는 PLC/HMI 온라인 쓰기 금지
- 실제 설치 환경의 자동화 테스트와 수동 Program Check 증거
