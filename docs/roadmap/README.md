# 재도입 로드맵

4.2.0은 schema v5 마이그레이션, 카탈로그/자산, 결선 편집 상태기, 내부 도통/점퍼, JSON·CSV 보고서를 유지합니다. 실행 진입점이 없던 기능은 제품 코드에서 제거하고 재도입 조건만 이 폴더에 둡니다.

- [XG-SIM](xgsim.md)
- [보고서 출력](report-export.md)
- [자동화·미션·3D](deferred-native-runtimes.md)

기존 v5 문서의 미션 상태와 시나리오, 뷰 배치는 손실 없이 읽고 씁니다. 미션 평가기, 자동화 2D 런타임, XG-SIM 호스트와 Direct3D 3D 렌더러는 현재 제품 기능이 아닙니다.
