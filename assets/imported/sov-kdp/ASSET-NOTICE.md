# SoV-KDP 선별 자산 이식 기록

이 폴더의 파일은 사용자가 수정·재사용 권한을 받았다고 명시한
`SoV-KDP 1.1.9K` Unity 빌드에서 2026-08-11에 선별 추출한 교육용 장비
메시와 텍스처입니다.

## 포함 범위

- Mitsubishi Q 계열 PLC/위치결정 모듈 외형
- 2축 서보 전체 장비 어셈블리 `servo2-workshop.glb`
- 공급·가공·이송·배출 모듈을 포함한 전체 MPS 스테이션
  `mps-complete-station.glb`
- 서보 앰프
- 공압 서비스 유닛, 분배기, 속도조절기, 복동 실린더
- 5/2 단·복솔레노이드 밸브, 광센서, 금속/플라스틱 작업물
- 각 GLB에 WebP로 내장된 장비 스티커 및 패널 텍스처

매니페스트 기준 결과는 13개 GLB(합계 17.45 MiB)입니다. 강의실, 의자,
책상, 벽, 그림과 중복 장비 GLB는 포함하지 않습니다. 텍스처는 GLB 안에 최대
2048px WebP로 내장하며, 중복되는 별도 PNG 파일은 배포 패키지에서 제외합니다.

결선 작업장에서는 `servo2-workshop.glb`와 `mps-complete-station.glb`를 각
실습실의 주 시각 모델로 사용합니다. 원본 공압 실습실에는 완성된 공압 회로가
저작되어 있지 않아, 위 원본 공압 장비 프리팹만 경량 장비 전용 장면에 조합해
사용합니다.

축 이동·센서·액추에이터·공압 계산 및 인터록은 Unity 동작을 복사한 것이 아니라
결선 작업장용 JavaScript 런타임으로 독립 구현했습니다.

## 제외 범위

- 로그인 계정, 비밀번호 및 자동 로그인 데이터
- 인증·라이선스·USB 동글·사용기간 제한 구현
- 실행 파일, 관리/네이티브 DLL, Unity 동작 코드 및 원본 프로그램 코드
- 외부 서버 주소, 네트워크 클라이언트, PLC 통신 프레임
- 사용자 저장 데이터와 교육기관별 설정

원본 빌드는 읽기 전용 입력으로 사용했습니다. 변환 결과와 SHA-256, 원본
Unity 오브젝트 이름/파일/path ID는 [manifest.json](manifest.json)에 기록됩니다.

## 재현

Python 3.11 환경에 `UnityPy`, `trimesh`, `pygltflib`, `Pillow`를 설치한 뒤
프로젝트 루트에서 다음처럼 실행합니다.

```powershell
python scripts/extract-sov-kdp-assets.py --source "<SoV-KDP_Data 경로>"
```

스크립트는 입력 폴더 안에 파일을 만들지 않으며, 결과는 이 폴더에만
기록합니다. 배포용 경량 추출에는 `--skip-textures`를 사용합니다.

이 기록은 사용자가 밝힌 권한의 법적 범위를 독립적으로 보증하지 않습니다.
재배포 범위는 실제 권리자와 합의한 조건을 따릅니다.
