# PLC 결선 작업장 v2.2

PLC 및 제어반 결선을 연습하고, 실제 장비 결선 전 핀투핀·전원·대표 I/O 상태를 오프라인에서 점검하는 Windows Electron 앱입니다.

> 이 앱은 통전 승인서나 전체 전기설계 계산 도구가 아닙니다. 실제 통전 전에는 해당 품번의 최신 제조사 매뉴얼과 자격자의 현장 확인이 필요합니다.

## 작업 모드

- **연습 모드**: 전체 교육용 장비와 7개 공개 미션을 사용합니다. 힌트는 개념 → 장비 → 단자 → 한 단계 정답 순으로 열립니다.
- **사전 결선 검토 모드**: 검증 프로필과 논리 시험 경계 노드만 표시합니다. 명시적으로 장비 역할을 지정한 뒤 안전 검증과 결정적 I/O 시험을 실행합니다.

사전 검토 모드의 최초 매뉴얼 검증 프로필은 다음 세 가지입니다.

- LS ELECTRIC `XBC-DR32H`
- LS ELECTRIC `XBF-AH04A`
- MEAN WELL `MDR-100-24`

`SV-iG5A`와 `XY-MD02`는 정확한 품번 또는 공식 제조사 근거가 확정될 때까지 연습 전용입니다. AC/DC 공급원, 건접점, 부하, RS485 상대 노드는 시험 경계이며 BOM에서 제외됩니다.

## 공개 미션

1. MDR AC 입력과 DC24V 배전
2. XBC 입력의 소스/싱크 결선
3. XBC 릴레이 출력 강제 시험
4. XBF-AH04A 전압·전류 채널 결선
5. iG5A 단자 제어 연습
6. MD02 RS485 결선 연습
7. 도어 기기와 내부 단자대 경유 배선

## 설치·실행

정식 배포 대상은 Windows x64 오프라인 Electron입니다. `index.html` 더블클릭 실행은 지원 대상이 아닙니다.

```powershell
npm ci
npm start
```

인터넷 연결은 의존성 설치와 개발 빌드에만 필요합니다. 빌드된 앱은 외부 CDN이나 네트워크 요청 없이 동작합니다.

## 검증과 빌드

```powershell
# 기존 회귀 + 도메인 단위 테스트 + 타입 검사 + 렌더러 빌드
npm run verify

# Electron 전체 흐름, 접근성, 오프라인 요청 검사
npm run test:e2e

# 100개 장비·300개 배선 검증 p95 성능 게이트
npm run test:performance

# Windows x64 포터블 실행 파일
npm run build
```

포터블 실행 파일은 `release/결선작업장-2.2.0-portable.exe`에 생성됩니다. 기존 배포 파일은 `npm ci`, 모든 테스트, 타입 검사, 렌더러 빌드, E2E, 포터블 빌드가 모두 통과한 뒤에만 교체하십시오.

로컬 빌드는 코드 서명 인증서를 자동으로 제공하지 않습니다. 서명 인증서를 설정하지 않은 EXE는 Windows SmartScreen 경고가 표시될 수 있으므로 외부 배포 전 별도 서명 절차가 필요합니다.

검증 성능은 워밍업 뒤 40회 표본의 p95가 250ms 이하인지 자동 검사합니다. 드래그 프레임 측정은 E2E에서 30fps 이상을 목표로 반복 측정하지만, GPU·원격 데스크톱·전원 관리 설정의 영향을 받으므로 시험 환경도 함께 기록해야 합니다.

## 판정과 리포트

- 정적 검증과 시뮬레이션은 동일한 `CircuitGraph`를 사용합니다.
- 상/N, DC+/0V, PE, 독립 전원 병렬, 전원 없는 MDR 출력, PLC COM·입력과 강제 릴레이 출력, 아날로그 모드, RS485 극성을 검사합니다.
- `PASS`는 필수 시나리오가 모두 끝나고 차단 오류가 없을 때만 반환합니다.
- 안전·기능 오류는 `FAIL`, 프로필·데이터·엔진 조건이 부족하면 `BLOCKED`입니다.
- 문서가 수정되면 이전 결과는 `STALE`이 되며, 리포트 내보내기 직전에 다시 검증합니다.
- 교육용·누락·로컬 강등 프로필 또는 `FAIL/BLOCKED/STALE` 결과가 있으면 검증 통과 리포트를 발급하지 않습니다.

리포트에는 전체 이슈, 핀투핀 표, 장비 설정, BOM, 문서 revision/hash, 프로필 버전, 매뉴얼 식별자·페이지·해시가 포함됩니다. 근거 PDF 원본은 개발 자료이며 실행 파일에 포함하지 않습니다.

## 저장 형식과 이전 데이터

새 저장 형식은 `WorkshopDocument v2`입니다. 기존 JSON과 `localStorage` 데이터는 결정적이고 멱등적으로 변환하며 원본은 삭제하지 않습니다. 알 수 없는 필드는 `extensions.legacy`에 보존하고, 기존 타입명이 같다는 이유만으로 검증 프로필에 자동 승격하지 않습니다. 손상된 JSON은 격리하고 원문을 유지합니다.
